## **How to add a new entry**

1. Find the year section above.
2. Add a row with `Date | Competition | Result | Team`.
3. For **award winners**, wrap the name in `**bold**` and use 🏆 🥈 🥉 🏅 in the Result column.
4. Create a detail page (folder + `.md` + certificate image) following the `Lab Seminars` pattern.
